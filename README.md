# Multi-Environment-AWS-Infrastructure-with-Terraform-
Rebuilt my existing HA web app, but entirely in Terraform with separate dev/staging/prod workspaces or modules, remote state in S3 + DynamoDB locking, and variables for environment-specific sizing. 
● Architected and provisioned a highly available, multi-environment (dev/prod) AWS 
  infrastructure entirely as code using Terraform, managing [40+] resources across 
  reusable modules.
● Implemented remote state management with S3 and DynamoDB locking to enable safe, 
  concurrent infrastructure changes across environments.
● Validated fault tolerance by terminating live instances and confirming automatic 
  replacement and traffic rerouting within seconds.
